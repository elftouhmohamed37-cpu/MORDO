# MORDO

MORDO is a free Android self-control/content blocker.

Current test build includes:
- adult website/domain blocking
- keyword/content blocking
- selected-app blocking engine
- Accessibility blocking service
- full-screen blocking overlay
- optional Device Admin removal friction
- Myself Mode challenge
- 15-minute cooling-off delay after passing the challenge

This repository is configured to build Android APK/AAB artifacts automatically with GitHub Actions.

## Status
Early test build. The final goal is feature parity with the core BlockerHero workflow while remaining free.
